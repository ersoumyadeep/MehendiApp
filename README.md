# 🌿 Rinki Mehendi Art

A beautiful and fully responsive **Mehendi Website** built using **HTML, CSS, and JavaScript**.

This website is designed for a professional Mehendi artist to showcase designs, services, pricing, and allow customers to submit booking requests.

## ✨ Features

* 📱 Fully responsive design
* 🏠 Attractive hero/home section
* 👩‍🎨 About Mehendi artist section
* 🎨 Mehendi designs gallery
* 💰 Services and pricing section
* ⭐ Why choose us section
* 📞 Contact information
* 📝 Booking request form
* 🍔 Responsive mobile navigation menu
* 🔝 Back-to-top button
* ✨ Smooth scrolling
* 🎭 Scroll animations
* 📧 Email contact option

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Interactions and functionality
* **Google Fonts** — Playfair Display & Poppins

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/mehendi-website.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the website

Open:

```text
index.html
```

in your browser.

You can also use the **Live Server** extension in VS Code.

## 📱 Responsive Design

The website is optimized for:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

The navigation menu automatically changes into a mobile hamburger menu on smaller screens.

## 📸 Website Sections

### 🏠 Home

Introduces the Mehendi artist and provides buttons to explore designs and book a service.

### 👩‍🎨 About

Provides information about the Mehendi artist and displays experience and client statistics.

### 🎨 Designs

Displays different Mehendi categories:

* Bridal Mehendi
* Arabic Mehendi
* Minimal Mehendi
* Festival Mehendi

### 💰 Services

Includes:

* Bridal Mehendi
* Engagement Mehendi
* Party Mehendi

### 📞 Contact

Customers can provide:

* Name
* Phone number
* Service
* Date
* Message

## 📧 Email

The website includes an email contact option using:

```html
<a href="mailto:your-email@gmail.com">
    📧 your-email@gmail.com
</a>
```

Replace `your-email@gmail.com` with your actual email address.

> Note: The current booking form does not automatically send emails. For real email delivery, connect the form to a backend such as Django or an email service.
